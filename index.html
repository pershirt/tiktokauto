What TikTok Clipper Does

A fully automated pipeline from YouTube trending to TikTok publishing

🔍

Trend Scanner

Scans trending videos on YouTube across France, USA, and United Kingdom. Monitors 22+ popular YouTubers including MrBeast, Squeezie, Sidemen, and more.

🧠

AI Highlight Detection

Uses OpenAI Whisper for speech transcription and a custom scoring algorithm that detects exclamations, laughter, loud peaks, and emotional keywords in English and French.

✂️

Smart Clip Cutting

Automatically cuts the 3 best moments from each video (configurable duration) in 9:16 vertical format (1080×1920), optimized for TikTok.

🇫🇷

French Subtitles

Burns subtitles directly into each clip with automatic English-to-French translation using a local ONNX MarianMT model. No cloud API needed.

📝

Smart Captions & Hashtags

Auto-generates engaging French captions and relevant hashtags (#PourToi #FYP #Viral) based on video content, channel name, and trending tags.

🚀

One-Click TikTok Publishing

Directly publishes clips to TikTok via the official Content Posting API with OAuth2 PKCE authentication. Supports public, friends-only, or private visibility.
